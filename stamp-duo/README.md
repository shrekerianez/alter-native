# AlterNative Stamp Manager Duo · PWA 0.2.0

Первый прототип редактора печатей и подписей, спроектированный специально под **iPhone Duo (iOS / Safari 27.1)**. Никаких Restore, ИИ и облачного сервера обработки документов.

## Что уже реализовано

- **Duo закрыт**: бордовая кожаная папка «НА ПОДПИСЬ», золотое тиснение, герб, застёжка и замочек. Кнопка запускает системную процедуру WebAuthn; в первый раз создаётся ключ доступа, при последующих запусках он используется для подтверждения личности. iOS сама выбирает доступный способ проверки, включая биометрию или код устройства.
- **Duo раскрыт без разблокировки**: полностью закрытый редактор и красная печать «СОВЕРШЕННО СЕКРЕТНО».
- **Duo раскрыт после разблокировки**: библиотека печатей и подписей слева, PDF в центре, инструменты справа.
- Импорт PDF (до 100 МБ), просмотр многостраничного файла, переход по страницам и масштаб.
- Импорт печатей и подписей PNG/JPEG/WebP до 12 МБ, сохранение в IndexedDB.
- Постановка изображения на страницу касанием, передвижение, изменение размера, поворот и прозрачность.
- Undo/redo, удаление наложения, автосохранение локального черновика.
- Экспорт исходного PDF с наложениями в единый PDF через pdf-lib, отправка через Share Sheet или скачивание.
- Три очевидно демонстрационных образца для проверки интерфейса (не реальные печати).
- Manifest, Service Worker, адаптация под safe areas. API сгиба подключены там, где их поддерживает Safari.

## Быстрый запуск через GitHub Pages

1. Создать отдельный репозиторий, например `alter-native-stamp-duo`.
2. Загрузить **содержимое** этого архива (файлы `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, папку `assets`) в корень ветки `main`.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. На iPhone Duo открыть `https://USERNAME.github.io/alter-native-stamp-duo/`, через Safari нажать «Поделиться → На экран Домой».
5. В **Настройки → Приложения → Safari → Дополнительно → Feature Flags** включить **Device Posture API** и **Viewport Segments API**, затем заново открыть PWA.

## Проверка интерфейса (без настоящего Duo)

Только для теста внешнего вида (без биометрии) поддерживаются параметры адреса:

- `?preview=1&pose=closed` — закрытая папка.
- `?preview=1&pose=open` — раскрытый интерфейс. Кнопка «Разблокировать» запускает демонстрационный вход.

`preview=1` **обходит проверку личности**. Не используйте этот режим с конфиденциальными документами. Удалите его из финального релиза.

## Важно: ограничения первой версии

1. **Сейчас замок является UX-блокировкой, а НЕ шифрованием файлов.** Документы и печати лежат в локальной базе браузера без шифрования. WebAuthn подтверждает действие через системный механизм, но не привязывает криптографический ключ расшифровки к проверке. Нельзя обещать безопасность уровня «совершенно секретно». До реального использования чувствительных документов потребуется отдельный дизайн сквозного шифрования/веб-ключей и оценка угроз.
2. **PDF.js и pdf-lib пока подключаются с jsDelivr.** При первом открытии PDF нужен интернет. Service Worker кэширует библиотеки после успешного использования, чтобы они стали доступны офлайн. Для полноценной автономной сборки скопируйте в `vendor/` локальные сборки PDF.js (`pdf.min.js`, `pdf.worker.min.js`) и pdf-lib (`pdf-lib.min.js`), поменяйте адреса в `app.js` и включите их в `SHELL` в `sw.js`.
3. Это первый прототип. Изменения PDF на реальном Duo/Safari 27.1 **пока не проверены**: нужно отдельно протестировать положения устройства, масштаб, попадание пальца по handles, WebAuthn, страницу «На экран Домой», экспорт/Share Sheet, многостраничные PDF, документы с поворотом страниц.
4. Device Posture API в Safari 27.1 возвращает `continuous` и для закрытого, и для полностью открытого телефона. Поэтому раскрытие сейчас определяется сочетанием segments/posture и пропорций viewport; универсального безошибочного аппаратного индикатора раскрытия у веб-приложения нет.
5. Safari 27.1 резервирует боковую системную полосу за пределами области веб-контента. Её нельзя заполнить собственными элементами PWA.
6. Первый прототип не умеет автоматически удалять белый фон сканированных JPG и не предоставляет полноценный режим правки самих объектов PDF. Для печатей лучше импортировать прозрачные PNG.
7. Библиотека и черновик хранятся в IndexedDB **конкретного браузера и origin**, не синхронизируются с macOS Stamp Manager и могут исчезнуть при очистке данных Safari.

## Разработка

Простой статический проект без сборщика и backend. Версия `0.2.0`. HTML/CSS/JavaScript. Основной формат разметки PWA использует относительные пути для GitHub Pages.


## Обновление интерфейса v0.2 (16 ноября 2026)
- Внешняя кожаная папка и экран «Совершенно секретно» сохранены.
- Внутренний редактор переработан: меньше декоративных рамок, больше места для PDF; библиотека стала компактнее.

- Это тестовый PWA: биометрическая проверка не гарантирует криптографическую защиту локальных документов.
