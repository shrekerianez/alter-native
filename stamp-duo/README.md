# AlterNative Stamp Manager Duo PWA

**Версия 0.3.0.** PWA для складного iPhone Duo, рассчитанное на раскрытый экран. Без Restore и ИИ.

## Что нового в v0.3

- Полностью переработано рабочее пространство: документ по центру, светлая библиотека слева, без постоянной правой панели инструментов.
- Библиотеку можно свернуть кнопкой слева в верхней панели. Это освобождает пространство для PDF.
- Упрощена верхняя панель: открытие PDF, отмена, повтор, экспорт, блокировка.
- Добавлены кнопка «Вписать» для восстановления масштаба и компактный режим отображения страницы целиком.
- На двух размерах тестового браузера (730×510 и 630×430 CSS px) проверено отсутствие горизонтального переполнения и работа раскрытия/скрытия библиотеки.
- Переписано кэширование Service Worker: для интерфейсных файлов сначала проверяется сеть, чтобы устаревший UI не залипал в PWA.

## Возможности

- Импорт и просмотр многостраничных PDF; смена страниц, масштабирование.
- Локальная библиотека изображений печатей и подписей (PNG, JPG, WebP).
- Установка на страницы, перемещение, масштабирование, поворот, прозрачность и удаление элементов.
- Отмена и повтор действий, экспорт нового PDF.
- Черновик в IndexedDB, офлайн-PWA после получения нужных PDF-библиотек.
- Внешняя кожаная папка; при раскрытии без авторизации экран «Совершенно секретно».
- Системная WebAuthn-проверка при разблокировке (если поддерживается браузером).

## Публикация

Файлы помещаются в каталог `stamp-duo/` на GitHub Pages: `https://shrekerianez.github.io/alter-native/stamp-duo/`. GitHub Pages поддерживает статическую PWA.

## Предупреждения

- **Шифрования локальных PDF и печатей в этой версии нет.** WebAuthn-замок защищает UI, но не содержимое IndexedDB. Не используйте v0.3 для конфиденциальных документов.
- PDF.js и pdf-lib подключаются с CDN при первом использовании, а затем могут кэшироваться. Поэтому полноценный офлайн-доступ зависит от успешной первоначальной загрузки.
- Работа реального iPhone Duo, Device Posture API, Viewport Segments API, Touch ID/WebAuthn и системных Safari UI не подтверждена в этом тестовом окружении.
- Тестовые скриншоты созданы браузерным движком Chromium с макетом PDF, **не являются проверкой настоящего PDF-рендера на Duo**.
- Экспорт из PDF не создаёт квалифицированную электронную подпись.

## Управление

1. В закрытом состоянии нажмите «Разблокировать» и подтвердите доступ.
2. Раскройте Duo и откройте PDF.
3. Выберите печать/подпись из библиотеки и коснитесь нужного места на документе.
4. Используйте жесты, масштабирование и панель свойств, затем «Экспорт PDF».

Если установленная PWA показывает старые стили: откройте приложение через Safari, перезагрузите страницу, затем закройте и снова запустите ярлык с домашнего экрана.
